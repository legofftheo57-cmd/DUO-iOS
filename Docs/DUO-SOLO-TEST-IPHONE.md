# Réception sur ton iPhone — après installation

Les résultats du simulateur ne prouvent pas la signature ou le fonctionnement sur ton appareil. Ces derniers contrôles physiques restent à faire.

1. Ouvrir DUO. Vérifier les cinq onglets **Accueil, Tâches, Courses, Planning, Nous**. Ouvrir Cuisine depuis l’accueil, Joe et Réglages. Vérifier la lisibilité avec ta taille de texte habituelle.
2. Créer une tâche, modifier son nom, la terminer, passer sur **Terminées**, la rouvrir, revenir sur **À faire**. Créer/cocher une course et ajouter un rendez-vous.
3. Dans **Nous**, vérifier trois activités. Valider la première, quitter complètement DUO, rouvrir : la validation doit être conservée. Toucher de nouveau pour l’annuler. Les suggestions changent au changement de date locale ; aucune activité n’est obligatoire.
4. Préparer une copie JSON dans **Réglages → Confidentialité**, puis utiliser **Enregistrer ou partager l’export → Enregistrer dans Fichiers**. Vérifier que le fichier existe hors de DUO.
5. Avec uniquement ces données d’essai : ajouter une course « Après export », restaurer le JSON de l’étape 4 et confirmer. Cette course doit disparaître, les données de l’export revenir. Enregistrer la **copie avant restauration**, puis la restaurer pour vérifier le retour de « Après export ». Toujours conserver la copie externe avant d’essayer.
6. Au prochain renouvellement de signature, installer par-dessus avec le même compte et identifiant d’application. Vérifier que les données sont toujours présentes.

Si un échec apparaît, noter l’action, le message exact, le modèle d’iPhone et la version iOS. Ne transmettre ni identifiant secret, ni mot de passe, ni code Apple.
